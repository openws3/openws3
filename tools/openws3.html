Experimental beta firmware

OpenWS3 is early software and testing is still ongoing, so it has not seen every cell, supply and load yet. You are charging lithium cells with it, at your own risk.

  • Supervise the charger the whole time it charges. Never leave it charging unattended or overnight.
  • Charge only cells in good condition, and pick the target voltage for the cell: 4.35 V is for high-voltage (HV) cells only.
  • It is made for the WhoopStor V3 charger only. See the user guide for how to use it.

Questions, problems, news

There is a Discord server for OpenWS3: installing it, flashing problems, charging behaviour, bug reports, and word of new releases. It is the quickest place to get an answer, and a report there helps the next person with the same charger.

Already running OpenWS3?

Plug the charger in with USB-C, press Connect and pick OpenWS3 in the list.

This browser cannot talk to USB devices: use Chrome, Edge or another Chromium browser.

Install OpenWS3 on your charger

Before you install, check that this charger is a WhoopStor V3 (six ports, a 160 x 80 colour screen, two buttons, USB-C). OpenWS3 is written for that board. On another charger, or another hardware revision, it can drive the power stage wrongly. If you are not sure, do not install it.

Installing replaces the firmware now on the charger, and this page does not keep a copy of it. The manufacturer's firmware can be put back later with the vendor's update package. Take all cells out of the charger first.

Only the USB-C cable and this page are needed.

  1. Unplug the USB-C cable from the charger.
  2. Press and hold the left button (the one for start / stop / current set).
  3. Keep holding it and plug the USB-C cable in. The screen stays dark; you can let go.
  4. Press the button below and pick the new entry in the list.

Nothing is changed until you confirm on the next screen. If the list is empty, repeat steps 1 to 3 (hold the button before plugging in, and use a data-capable cable).

Linux: no device in the list?

The browser needs access to the device. Once, as root, then replug the unit:

echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="34bf", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/99-openws3.rules
sudo udevadm control --reload-rules

Charger

Current and voltage can be changed while the charger is stopped. The storage voltages leave a cell at about half charge for long-term storage. Esc stops charging.

Supply and inputs

Charger

Limits

Setpoints

What the charger regulates to: the cell target voltage, the rail it holds for that target, the charge current setting. Each port shows its own current setpoint while it charges and whether the limiter holds it below that.

Rail

Regulated: the firmware's PI loop holds the rail at the setpoint (vu, 1.0986 mV each, at most 3972 = 4.35 V). Raw duty: the PWM as given; a higher duty means a lower rail, and only the rail over-voltage cut stops it going too high.

Enables

Input profile: switching it off can pull the input below its minimum (seen on a 5 V supply), which holds the port outputs off. The fan also runs whenever the board is warm. The main power enable is not offered (it would cut the unit's own supply). Port outputs stay off without the global enable.

Ports

Voltage and current of each port. The plot shows the current over the last 10 s. Each port's current: auto follows the charge current setting, off leaves the port out of the run (not while charging).

While charging, each port also shows its current setpoint and whether the limiter holds it below that (waiting: no current until there is room).

PWM 0..400 per port; BLEED switches the port to its discharge path. A port above 4.40 V or 2.8 A is cut by the firmware until it is set to 0 and the bleed switch off. The plot shows the current over the last 10 s.

Events

    Firmware

    A running OpenWS3 restarts into its loader by itself, takes the new firmware and starts again (not while charging). Do not unplug the charger meanwhile. If an update is ever interrupted, hold the left button while plugging in USB-C and install again. "Check the unit" only reads: it restarts the charger into its loader, reports the chip and the area it keeps its settings in, and starts the firmware again.
